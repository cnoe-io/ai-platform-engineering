# Insights

![Aggregate CAIPE usage and adoption statistics](/img/features/insights.svg)

Insights helps administrators understand how the platform is being used. It is
an operational adoption surface, not a billing or employee-performance system.

## Statistics

Available statistics can include:

- Active users and conversations
- Top users and agents
- Response-time and hourly activity trends
- Workflow configuration and run outcomes
- Skill catalog, category, creator, and run metrics
- Slack activity when the integration is enabled

Filters and exact sections depend on the available data stores and configured
services.

## Feedback

When feedback is enabled, administrators can review positive and negative
message feedback from supported surfaces. Entries can include conversation
metadata, a limited content snippet, submitting identity, reason, trace ID, and
an integration permalink.

Use feedback to prioritize product and agent improvements. Do not copy message
content into external systems without checking its classification and sharing
scope.

## Interpreting Results

- A high conversation count does not prove successful outcomes.
- A low feedback count can mean low usage or low feedback participation.
- Runtime latency can include model and external-tool time.
- Service accounts and bots must be distinguished from people in user metrics.
